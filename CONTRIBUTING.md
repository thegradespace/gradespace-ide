# Contributing

Gradespace IDE is developed by the Gradespace team. We do not accept pull requests from people who
are not collaborators on this repository. Pull requests from anyone else will be closed without
review, and only collaborators can merge.

Found a bug? Open an issue. Found a security problem? Email
[security@thegradespace.com](mailto:security@thegradespace.com) instead of opening an issue. See
[SECURITY.md](./.github/SECURITY.md).

## Developer setup

See the [development runbook](docs/operations/development.md#first-checkout) for the first
checkout, development commands, tests and desktop packaging. Collaborators should also read
[AGENTS.md](./AGENTS.md).
