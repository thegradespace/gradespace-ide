# My changes to T3 Code

Check these still work after merging a release from `upstream`.

- **`vp run dev` opens the browser.** In a terminal it opens the pairing URL; `--no-browser` skips it. Stays closed for `--share`, `--host` and background runs. (`scripts/dev-runner.ts`)
- **Panel position setting.** Settings → Appearance → Panel position → Left puts the files/diff/browser panel left of the chat, with the file tree on its outer edge. Covers the thread view and the pull requests page. (`panelSide` in `packages/contracts/src/settings.ts`; `ChatView.tsx`, `PreviewPanelShell.tsx`, `FileExplorerPane.tsx`, `usePreviewPanelInlineSize.ts`)
- **Terminal position setting.** Settings → Appearance → Terminal position → Under panel moves the terminal drawer under the files/diff panel while it is open inline; it falls back under the chat otherwise. (`terminalPlacement` in contracts settings; `ChatView.tsx` `terminalInPanel`, `footer` prop on `RightPanelTabs.tsx`)
- **Collapsed sidebar rail.** On desktop widths, collapsing the sidebar leaves a narrow rail of recent threads as project icons (tooltip shows thread and project; dot = needs input). (`components/sidebar/SidebarCollapsedRail.tsx`, mounted in `AppSidebarLayout.tsx`; header inset override at the end of `index.css`)
- **Gradespace branding.** Logos live in `apps/web/public/brand/` (`gradespace-logo-light.png` = black text for light theme, `gradespace-logo-dark.png` = white text for dark theme and the stage backdrop, `gradespace-ide-small.svg` = simplified IDE mark for small sizes). The sidebar header uses the logos (`SidebarBrandMark` in `SidebarChrome.tsx`); the collapsed rail uses the small IDE mark. The boot splash in `apps/web/index.html` is the animated "Gradespace IDE" loading screen (`#boot-shell-card`, `boot-*` keyframes).
- **Move terminals between drawer and panel.** The terminal toolbar has a move button: in a panel tab it moves the terminal to the bottom drawer, in the drawer it moves it to a panel tab. Sessions keep running. (`onMoveTerminal` in `ThreadTerminalDrawer.tsx`; handlers in `PersistentThreadTerminals.tsx`)
- **API-key spend on the Limits tab.** Providers signed in with an API key (Claude and Codex report `auth.type === "apiKey"`) get a section under the subscription bars with estimated spend today and this month, using the Cost tab's transcript data. The Limits refresh button rescans it. (`components/usage/UsageApiKeySpend.tsx`, mounted in `UsageLimitsSection` in `UsageLimits.tsx`)
- **Gradespace IDE icons.** `favicon.ico` (16–256px), `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `icon.svg`, `icon-192.png`, `icon-512.png` and `icon-maskable-512.png` in `apps/web/public/` come from the designer files; `manifest.webmanifest` lists them. `index.html` links only the `.ico` (with `?v=ide` to bust caches) because the unread badge in `threadNotifications.ts` swaps just the first icon link. Upstream releases may overwrite these files.
- **Privacy: analytics opt-in and offline mode.** Settings → Maintenance → Privacy. "Share usage data" (`shareUsageData`, default off) gates `AnalyticsService` record and send; `T3CODE_TELEMETRY_ENABLED=false` still forces it off. "Offline mode" (`offlineMode`) also stops provider version checks (`snapshotSettings.ts`), the model catalog fetch (`ModelManifest.ts`) and the LiteLLM price download (`UsageService.ts` uses the saved copy). Desktop app auto-updates and Google website icons are not covered. Test: "sends only after opting in" in `AnalyticsService.test.ts`.
- **Gradespace IDE name.** `APP_BASE_NAME` in `apps/web/src/branding.ts` (window title and app name), `<title>` in `index.html`, and `name`/`short_name` in `manifest.webmanifest`. About page (`AboutSettingsPanel` in `SettingsPanels.tsx`): version says "built on T3 Code", the Privacy row links to Privacy settings and T3's policy, licenses mention T3 Code; the mobile row says it is T3 Code's app (`MobileAppSettingsRow.tsx`).
- **GS naming.** "Gradespace IDE" is the full name (window title, About, setup wizard); "GS" is the short name in running text across web, server and CLI messages. "T3 Code" stays only where it means T3's project or services: attribution, licenses, analytics, T3 Connect, the GitHub star prompt, reinstall links, the SnapShots GNOME extension and the `npx t3` package. `.github/triage/PLAYBOOK.md` and its copy in `triagePrompt.ts` must stay byte-identical, so they are not renamed. Logo on standalone pages and the setup wizard: `components/GradespaceLogo.tsx`. Chat timeline rows use the one-colour G from `components/GradespaceMark.tsx`.
- **`gs` command.** Root command, help and printed hints say `gs` (`CLI_COMMAND` in `apps/server/src/cli/invocation.ts`, `binCli.ts`); the package also has a `gs` bin, and `t3` still works. `vp run gs:install` (`scripts/install-gs-command.ts`) writes a launcher to `/usr/local/bin/gs` that runs this checkout from source against `~/.t3/dev`; `vp run gs:uninstall` removes it. `gs update` still fetches upstream's `t3` package from npm, so don't use it on this fork. Two "manual server installation ownership" tests in `invocation.test.ts` fail on macOS because of the `/private` temp path, not because of this change.
- **Gradespace mobile app.** `apps/mobile` builds as Gradespace (`com.gradespace.ide`, scheme `gradespace://`) with icons in `assets/gradespace/`; EAS project, Expo owner and Apple team come from env vars. Pairing still accepts upstream `t3code://` links. Steps to build and publish, and what is lost without T3's services (push, T3 Connect, crash reports): `apps/mobile/GRADESPACE.md`.
- **Studio tab.** The panel's + menu has a Studio tab that compares option sets the agent writes to `.gradespace/studio/<date-name>/studio.json`, with pick, comment, edit and export. Web only, using the existing file RPCs. (`components/studio/`; `"studio"` surface in `rightPanelStore.ts`, `RightPanelTabs.tsx`, `RightPanelSurfaceContent.tsx`)
- **Dev server restarts.** `node --watch` covers `apps/server/src` and `packages/`, so editing them, or running `vp test` from the repo root (it writes `packages/*/node_modules/.vite-temp`), restarts the server and stops running agents. Do server work in a worktree and run tests from inside the app folder.
